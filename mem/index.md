# Project Memory

## Core
Video quality floor = "Base Level 2" (locked at worker v0.7.1). Motion Poster + Bold Editorial engines with two-colour invert, dynamic pacing and subtle directional entrances are the minimum acceptable quality. Never regress: no spin/shake/blur/random-layout experiments, no rewriting templates from scratch, no dropping brand colour respect, no captions inside the video.
Exactly TWO brand colours per reel (ink + field), inverting per slide. Never add a 3rd/4th colour.
Slide speed must vary per beat from copy meaning/pace — never fixed timing.
Text entrances: occasional, subtle directional drift only (see directional entrances memory). Never on every beat.
Hybrid Flow is the third template: per-beat it picks slide-move OR text-move OR both OR settle. Never make motion uniform across beats.
User speaks Hinglish, blunt, low patience for over-engineering. Do exactly what's asked, nothing extra.
